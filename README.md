# Proyecto INMO 1

Base real del proyecto inmobiliario.

## Stack inicial

- React
- TypeScript
- Vite
- GSAP
- Framer Motion
- Lucide React

Supabase y Google Maps se integrarán después de certificar la experiencia visual del Home.

## Arranque

En Windows / Git Bash:

```bash
cd ~/Desktop/"proyecto inmo 1"
npm install
npm run dev
```

Si descargaste este paquete, extraé su contenido dentro de:

```text
Escritorio/proyecto inmo 1
```

## Home V1 incluida

- Hero cinematográfico
- Header
- Manifiesto editorial
- 2 presentaciones cinematográficas adicionales
- Propiedades destacadas mock
- Comprar / Alquilar / Vender
- Sección de Ubicaciones preparada para Google Maps
- Footer
- Responsive
- `prefers-reduced-motion`
- Pausa automática de videos fuera del viewport
