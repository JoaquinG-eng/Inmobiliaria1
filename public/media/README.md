# Videos de la Home

El proyecto está preparado para tres archivos locales:

1. `hero-urban.mp4`
   Referencia: https://www.pexels.com/video/an-exterior-design-of-a-modern-house-7578541/

2. `villa-mountain.mp4`
   Referencia: https://www.pexels.com/video/modern-villa-in-scenic-mountain-landscape-34667982/

3. `villa-greenery.mp4`
   Referencia: https://www.pexels.com/video/aerial-view-of-lush-greenery-and-modern-villa-31454305/

Pexels entrega estos videos desde su propia página de descarga; la URL de la página no puede usarse directamente como `src` de un `<video>`.
Por eso el frontend ya está preparado y, mientras los MP4 no estén presentes, usa una imagen de respaldo.

Más adelante podemos reemplazar estos archivos por clips definitivos de Pexels, Pixabay, Mixkit o material propio sin tocar la estructura del Home.
